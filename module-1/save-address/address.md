# SAVE ADDRESS FEATURE
- Rule [user] [what] [why]

**USER STORY**
    As a returning customer, I want the checkout page to remember my shipping address, so that I don't have to re-enter it every time I order

**ACCEPTANCE CRITERIA** 
 - save address appears automatically on checkout for returning customers
 - customer can edit the pre-filled address before the order
 - If no address is saved, the form behaves exactly as it does today.
