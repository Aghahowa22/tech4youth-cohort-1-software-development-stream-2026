# JOB SEEKER CASE

**Searching For Remote Role**

## User-Story (who, what and why)
- As a user, I want search for remote role and apply for the job.

## Acceptance Criteria (Context, Action and Expected Result)
- Given I am on the job search page on linkend
- when filter the list of jobs with remote it should return only remote rol
- Then I can apply for the remote role

## How to verify we wrote a good user story
- user the INVEST METHOD
- Independent - it can developed and released on it own
- Negotiable - the method by which the goal is achive should be negotiable
- Valuable - each story should increase the product value
- Estimable - can be sized by the team
- Small - complete within a sprint
- Testable - in binary way either pass or fail
