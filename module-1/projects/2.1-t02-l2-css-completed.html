Flexbox Layout

Flexbox is a powerful tool for creating 1D layouts (either rows or columns). It's perfect for navigation bars, card layouts, and flexible sizing. In this project, we use flexbox to create a responsive navigation that adapts to different screen sizes.

Key Flexbox Properties:

  • display: flex — makes a container a flex container
  • flex-direction: row | column — sets layout direction (default is row)
  • justify-content — aligns items along the main axis (flex-start, center, space-between, etc.)
  • align-items — aligns items along the cross axis (center, stretch, etc.)
  • flex-wrap — allows items to wrap to the next line (default is nowrap)
  • gap — adds space between items (modern CSS, replaces margin tricks)
  • flex — shorthand for flex-grow, flex-shrink, and flex-basis

Real Example in This Project:

The navigation bar uses display: flex with responsive behavior. On mobile, links stack and take up space evenly. On tablet and up, they align left with fixed widths.

CSS Grid Layout

CSS Grid is perfect for 2D layouts where you need to control both rows and columns. It's ideal for page layouts, gallery grids, and complex designs. While this project uses Flexbox for the main layout, Grid is incredibly useful for more complex structures.

Key Grid Properties:

  • display: grid — makes a container a grid container
  • grid-template-columns — defines column widths (e.g., 1fr 1fr for two equal columns)
  • grid-template-rows — defines row heights
  • gap — adds space between grid cells
  • grid-column — spans an item across multiple columns
  • grid-row — spans an item across multiple rows
  • auto-fit / auto-fill — creates responsive grids without media queries

When to Use Grid vs. Flexbox:

  • Flexbox: One-dimensional layouts (rows or columns), navigation, flexible sizing
  • Grid: Two-dimensional layouts (rows and columns), page layouts, complex designs
  • Pro tip: Use them together! Flexbox inside grid items for ultimate flexibility

Responsive Design

Responsive design ensures your site looks good on phones, tablets, and desktops. Modern web design uses media queries and mobile-first thinking. This project uses mobile-first approach with three breakpoints: base (mobile), 768px (tablet), and 1200px (desktop).

Mobile-First Approach:

  • Write base styles for mobile first — no media query needed
  • Add media queries for larger screens — layer complexity as screen grows
  • Common breakpoints: 768px (tablet), 1200px (desktop)
  • Test on actual devices — don't just rely on browser resizing
  • Use relative units — em, rem, %, and viewport units instead of fixed pixels
  • Touch targets — buttons and links should be ≥48px on mobile

Media Query Syntax:

  • @media (min-width: 768px) { /* tablet and up */ }
  • @media (max-width: 767px) { /* mobile only */ }
  • @media (min-width: 768px) and (max-width: 1199px) { /* tablet only */ }
  • @media (orientation: landscape) { /* landscape mode */ }
  • @media (prefers-reduced-motion: reduce) { /* respects accessibility preference */ }

Responsive Image Technique:

To make images responsive, use: img { max-width: 100%; height: auto; } This ensures images scale down on smaller screens while maintaining aspect ratio.
