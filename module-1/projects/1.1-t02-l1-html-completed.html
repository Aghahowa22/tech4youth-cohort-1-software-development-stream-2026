Welcome to Web Development

Welcome to your journey into web development! In this course, you'll learn the fundamental technologies that power the modern web. Whether you're building your first website or preparing for a career in tech, understanding HTML, CSS, and accessibility is essential

The web is built on three core technologies: HTML for structure, CSS for style, and JavaScript for interactivity. But before diving into complex frameworks and tools, mastering the foundations is crucial. This course focuses on semantic HTML and modern CSS, ensuring your websites are not just beautiful, but accessible to everyone.

By the end of this course, you'll have built multiple projects, practiced accessibility testing, and understood the principles of inclusive design. Let's get started!

Your Learning Path

What We'll Cover

This course is organized into two main topics, each with three lessons:

  • Topic 01: Software Development Fundamentals — Understand roles, SDLC, and Agile
  • Topic 02: Web Development Essentials — Build semantic HTML, style with CSS, ensure accessibility

Each lesson includes theory, hands-on practice, and real-world examples. You'll build projects that demonstrate your learning and can be added to your portfolio.

Learning Objectives

  • Explain and use semantic HTML elements correctly
  • Structure web pages with landmarks and logical heading hierarchies
  • Write accessible forms, images, links, and tables
  • Style pages with modern CSS (Flexbox, Grid, Media Queries)
  • Ensure WCAG AA accessibility compliance
  • Test your work with browser tools and screen readers

Skills You'll Master

HTML Skills

  • Semantic markup with landmark elements
  • Proper heading hierarchy (h1–h6)
  • Accessible links with meaningful text
  • Images with descriptive alt text
  • Accessible forms with labels
  • Semantic tables with headers
  • Lists, paragraphs, and content grouping

CSS Skills

  • CSS selectors and specificity
  • The box model (margin, padding, border)
  • Flexbox for flexible 1D layouts
  • CSS Grid for 2D layouts
  • Responsive design with media queries
  • Mobile-first approach
  • Color contrast and typography for accessibility
  • Animations and transitions

Accessibility Skills

  • WCAG 2.1 Level AA guidelines
  • Keyboard navigation testing
  • Screen reader testing (NVDA, VoiceOver)
  • Automated accessibility tools (Lighthouse, axe)
  • Color contrast verification
  • Inclusive design thinking
  • Legal compliance awareness

Quick Tips for Success

  • Practice regularly: Build something every day, even if small
  • Test on real devices: Don't just test in your desktop browser
  • Use DevTools: Right-click → Inspect becomes your best friend
  • Read error messages: They're usually telling you exactly what's wrong
  • Ask questions: There's no such thing as a "dumb" question
  • Accessibility first: Build inclusive from day one, not as an afterthought
  • Reference the docs: MDN Web Docs is your trusted resource
