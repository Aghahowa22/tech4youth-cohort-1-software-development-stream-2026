Flexbox Layout

Flexbox is a powerful tool for creating 1D layouts (either rows or columns). It's perfect for navigation bars, card layouts, and flexible sizing.

Key Flexbox Properties:

  • display: flex — makes a container a flex container
  • flex-direction: row | column — sets layout direction
  • justify-content — aligns items along main axis
  • align-items — aligns items along cross axis
  • flex-wrap — allows items to wrap to next line
  • gap — adds space between items

CSS Grid Layout

CSS Grid is perfect for 2D layouts where you need rows AND columns. It's ideal for page layouts, gallery grids, and complex designs.

Key Grid Properties:

  • display: grid — makes a container a grid container
  • grid-template-columns — defines column widths
  • grid-template-rows — defines row heights
  • gap — adds space between grid cells
  • grid-column — spans multiple columns
  • grid-row — spans multiple rows

Responsive Design

Responsive design ensures your site looks good on phones, tablets, and desktops. Modern web design uses media queries and mobile-first thinking.

Mobile-First Approach:

  • Write base styles for mobile first
  • Add media queries for larger screens
  • Common breakpoints: 768px (tablet), 1200px (desktop)
  • Test on actual devices, not just browser resizing
